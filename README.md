# MBTATrack
# BUHHS 2026
MBTA Smart Commute is an intelligent transit assistant designed to help Boston commuters make faster, smarter decisions in the face of unpredictable train delays.

The core problem we address is that current transit tools provide raw information—such as schedules or alerts—but fail to guide users on what actions to take. Commuters are often left uncertain whether to wait, leave, or find alternatives, leading to wasted time and frustration.

Our solution combines machine learning with real-time transit data from the MBTA to transform uncertainty into actionable decisions. The system predicts both the probability and expected duration of delays using features such as time of day, day of week, seasonal patterns, station congestion hotspots, and active service alerts.

In addition to predictive modeling, the platform integrates live data feeds to display upcoming train arrivals and real-time train locations on an interactive map. This allows users to visually confirm system conditions rather than relying solely on estimates.
